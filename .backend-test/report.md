# 后端接口测试记录

日期：2026-10-01。仅测试后端，未修改业务源码。

使用本机 MySQL 和 Maven 启动当前源码，完成编译和 HTTP 接口检查。

## 通过的主要功能

- 临时用户注册、登录；重复注册和错误密码被拒绝。
- 注册请求即使带 ADMIN 字段，新用户仍为 USER；数据库 role 默认值确认是 USER。
- 无 token、无效 token、过期 token 返回 HTTP 401。
- 普通用户可查询，新增、修改、删除返回 HTTP 403。
- 管理员权限新增、详情查询、修改并核实年龄变化、删除并核实记录不存在。
- 姓名过滤；第一页与第二页返回不同记录，页码和总页数正确；无结果查询返回空列表。
- 空姓名、负数年龄、不合法分页范围被业务校验拒绝。
- 查询、修改、再次删除不存在的记录返回业务码 404。

管理员测试使用按项目签名规则生成的临时 ADMIN token，覆盖管理员接口权限路径，不代表验证了真实管理员账号登录。普通用户通过实际注册登录获取 token；分页补测使用项目 HTTP 文件中的测试账号。

## 已确认的问题

1. 新增学生未传 age 仍返回成功，数据库允许存储空年龄。若年龄必填，需要后端非空校验。
2. email 为 not-an-email 仍新增成功，缺少邮箱格式校验。
3. 校验失败、业务失败的响应 HTTP 状态通常为 200，JSON 内部 code 为 400/404；拦截器返回的 401/403 是正确 HTTP 状态。
4. 修改缺少 id 时返回业务 404 学生不存在，建议明确返回参数缺失 400。
5. page=abc 返回 HTTP 400，但没有统一 Result 的 code/message 字段。

当前样本分页测试通过；没有 ORDER BY 的分页 SQL 仍不能保证所有情况下排序稳定，本次没有复现分页异常。

## 清理和限制

- 临时数据按唯一标记清理：主测试删除测试学生后，清理程序删除剩余 2 名边界测试学生和 1 个测试用户。
- 不修改已有学生和用户，未重置数据库自增序列。
- 此记录是功能和部分边界测试，不是并发、压力或完整安全测试。
- 30 个主测试请求的响应摘要见 results.json；分页及空结果查询另行补测通过。
